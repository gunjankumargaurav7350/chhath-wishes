## 🌟 प्रमुख विशेषताएं (Key Features)

### 🎨 1. अल्ट्रा-लक्ज़री वेलवेट प्लम थीम (Screenshot Styled Design):
- डीप प्लम / रॉयल वाइन बैकग्राउंड पर एम्बिएंट फ्लोटिंग कमल के फूल, माटी के दीये एवं सोने के चमकते सितारे।
- **इंटरएक्टिव वाइब पिल्स (Top Vibe Bar)**:
  `[ 🪔 Light ]`, `[ 💰 Prosperity ]`, `[ ❤️ Love ]`, `[ 🙏 Surya Arghya ]`, `[ 🍬 Thekua Prasad ]`, `[ 🎆 Fireworks ]`, `[ ✨ Positivity ]`, `[ 👨‍👩‍👧 Family ]`.
  प्रत्येक बटन को टच करने पर अनोखा पार्टिकल ब्लास्ट व संगीत की गूंज।

### ✍️ 2. प्रामाणिक एवं हृदयस्पर्शी महा-शुभकामना (Authentic Hindi & English Poetry):
- डूबते और उगते सूर्य को अर्घ्य देने का पावन दर्शन।
- परिवार के सुख, शांति, समृद्धि और खुशहाली के लिए छठी मैया का विशेष आशीर्वाद।
- साथ में ग्लोबल ऑडियंस के लिए सुंदर इंग्लिश विश कार्ड।

### 🎵 3. ओरिजिनल छठ संगीत व शंखनाद (Original Audio & Synthesizer):
- **ओरिजिनल छठ गीत** बिना किसी बदलाव के सुरक्षित रखा गया है।
- पेज खुलते ही और किसी भी टच पर तुरंत ऑडियो शुरू होने की गारंटी।
- वेब ऑडियो एपीआई (Web Audio API) द्वारा सजीव मंदिर की घंटियां एवं शंखनाद।

### 📲 4. पर्सनलाइज्ड विश लिंक जनरेटर (Trending WhatsApp Sharing):
- अपना नाम और प्रेषक का नाम दर्ज करें।
- कस्टमाइज्ड लिंक तैयार होता है: `?from=Gunjan+Kumar+Gaurav&to=Dost`.
- 1-क्लिक **WhatsApp शेयरिंग** एवं **लिंक कॉपी** बटन।

## 📁 मॉड्यूलर आर्किटेक्चर (Modular Structure)

```plaintext
chhath-wishes/
├── index.html                   # सिमेंटिक स्वच्छ HTML5
├── css/
│   └── style.css                # लक्ज़री डार्क प्लम स्टाइलशीट
├── js/
│   ├── app.js                   # मुख्य एप्लीकेशन एवं WhatsApp शेयरिंग
│   ├── audio.js                 # ऑडियो इंजन एवं वेब ऑडियो सिंथेसाइज़र
│   └── effects.js               # कैनवास पार्टिकल्स, पटाखे एवं वाइब्स
├── audio/
│   └── chhath_song.mp3          # ओरिजिनल छठ गीत (सुरक्षित)
└── terraform/                   # टेराफॉर्म इंफ्रास्ट्रक्चर एज कोड (IaC)
    ├── main.tf                  # रूट मॉड्यूल
    ├── variables.tf             # इनपुट वेरिएबल्स
    ├── outputs.tf               # आउटपुट वैल्यूज
    ├── terraform.tfvars.example # वेरिएबल वैल्यूज उदाहरण
    └── modules/
        └── azure_static_web_app/ # अज़ूर स्टैटिक वेब ऐप मॉड्यूल
            ├── main.tf
            ├── variables.tf
            └── outputs.tf
```

यदि आप इस साइट को अपने Azure Cloud Subscription में Azure Static Web Apps पर डिप्लॉय करना चाहते हैं:
